# 평가자 점검 결과

판정 대상은 원천 PDF를 조사·채점하고 **세 기업의 완성 보고서와 검증 State를 종합해 하나의 최종 투자 보고서를 생성하는 코드**다. 최종 합성에서 기업별 해석이 빠지는 문제를 확인해 원보고서 전체 입력·문단 반영 맵·반영 Judge를 추가했다. 최신 실제 v10은 검증된 합성·선정을 재사용하고 품질을 새로 평가해 **8쪽·품질 통과**를 확인했다. 중간 통과 뒤 발견한 인용 오류는 원문 대조로 교정했으며, 최종 본문은 원문 검토를 마친 교정본과 동일하다. 최종 패키지·GitHub 제출 정보는 별도로 확인한다.

## State Schema — 7요건과 한계

| 요구 | 구현과 한계 |
|---|---|
| 제어 / 페이로드 분리 | 작업·라우팅·피드백·예산과 조사·투자·보고서 결과를 분리한다. 검색 인덱스와 원본 PDF는 State 밖에 둔다. |
| 관측성 위치 | State에 현재 부족 사유·시도·종료 사유, 외부 JSON/LangSmith에 노드 실행·판정 기록을 남긴다. |
| 지속성 비용 | 워커 누적을 유한 라운드로 제한하고 PDF·벡터는 파일/캐시로 관리한다. 전체 State 크기와 비용 상한은 없다. |
| 상관 | `trace_id`·checkpoint `thread_id`·실제 LangSmith graph run UUID·로컬 기록을 연결한다. |
| 재개 / 복구 | 조사 종료 후 Writer→Evaluator 복구, 검증된 원문만 재검증·재채점, 동일 입력 최종 분석 재사용을 지원한다. `InMemorySaver`로 일반 조사 중단의 영구 체크포인트는 제공하지 않는다. |
| 동시 처리 | `라운드:작업ID` reducer로 워커 결과를 병합하며 같은 키의 충돌 결과를 거절한다. 공용 카탈로그 병합은 Synthesizer가 수행한다. |
| 종료 보장 | 추가 조사 3~5회·무진전 2회·재작성 2회·recursion 상한을 두고, 아직 조사 기회가 없는 역할은 무진전 조기 종료에서 보호한다. 미확인은 U, 품질 미달은 초안으로 보존한다. |

## 품질 방식과 실제 실패 처리

Groundedness·중립성·편향 통제를 평가하며 **관점 커버리지는 제외**한다. 코드가 점수·U·인용·거래 방향·등급 단계·투자 조건을 검사하고 LLM Judge가 보고서와 원본 페이지를 대조한다. `findings`는 실제 문단·결함·수정 유형에 연결되고 같은 축의 결함이 있으면 그 축은 실패다. 자료 부재·U만으로는 품질 실패가 아니다.

원보고서 전체·SHA256·문단 ID를 합성·선정 모델에 전달한다. 회사별 5필드와 비교 2문단을 합성하고, 분석을 가져온 문단과 실제 원문 인용 위치를 별도로 기록한다. 같은 통합 Judge가 분석·한계·개별 의견의 **실제 반영**을 확인한다. 소제목·ID 존재만으로 통과시키지 않으며 원보고서의 과장을 원문에 맞게 교정한 것은 누락으로 취급하지 않는다.

실제 실행에서는 JSON 길이 상한의 문장 절단, 누락된 문단 ID, RL·MOU 목적·ROBROS 시장 인용 오류를 발견했다. 문장 완결성·연결 검사와 문단 인용↔원문 페이지 검사로 보강했다. 중간 LLM 통과 뒤 독립 원문 대조에서 발견한 오류도 수정했으므로 LLM 통과를 원문 정확성 보장으로 표현하지 않는다. 기업 사실·수치·비교는 해당 문단의 원문과 대조하고, 코드에서 파생된 최종 선정 라벨·조건부 결론은 검증된 Portfolio action·근거·같은 제안 구역의 인용된 이유/조건과 대조한다.

표현 결함은 근거·점수·REFERENCE·공식 결론을 유지해 최대 두 번 수정한다. 기업별 근거 결함은 남은 예산 내 재조사하며, 통합 단계의 새 근거 필요·예산 소진은 초안 종료다. 같은 문서를 반복 평가해 우연한 통과를 기다리지 않는다. 최신 v10은 교정된 v9 본문을 그대로 새 평가했고 `rewrite_count=0`이다. 이전 PNG 02~03의 합성 전 8쪽 통과와 별개의 실행이다.

## 오버헤드와 기업 운영

세 워커 병렬 실행과 세 조사 라운드 반복은 다르다. 필요한 역할·항목만 재계획하고, 동일 검증·임베딩을 재사용하며 표현 수정에는 워커를 호출하지 않는다. 정상 최종 경로는 새 검색·재채점 없이 합성 LLM 기본 1회를 추가하고 기업 반영 검사는 같은 Judge 호출에 포함한다.

`--combine-reports DIR --reuse-analysis JSON`은 원보고서·21항목 점수/사유·trace/상태·검증 주장·원문 전체 페이지/출처가 같은 경우만 합성·선정을 재사용한다. 분석을 품질/PDF 전에 저장하고 교정 본문·해시를 보존하며 품질은 새로 평가한다. 이전 항목 snapshot 없는 형식의 점수표 대조 제한은 [재현 안내](../SUBMISSION.md)에 기록한다. Supervisor 대비 호출·시간·비용 절감률은 미측정이다.

운영 도입 전에는 검색 Hit Rate@K·MRR, Judge 정답셋, 장기 실행의 저장·복구, 전체 비용 상한을 검증해야 한다. 현재 결과를 production-ready 또는 검증된 투자 성과로 표현하지 않는다.
